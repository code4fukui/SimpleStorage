# SimpleStorage

Denoで開発された簡易ストレージサーバーサービス。

## デモ
[https://ss.sabae.cc/](https://ss.sabae.cc/)

## 機能
- HTMLデータの保存
- パスワードによる保護機能
- 簡単なAPI利用による操作

## 必要環境
- Ubuntu
- Nginx
- Let's Encrypt (certbot-auto)
- Deno

## 使い方
1. Ubuntuをセットアップ
2. Nginxをインストール
3. Let's Encryptを設定
4. [Deno](https://deno.land/)をインストール
5. `SimpleStorage`リポジトリをクローンし、`run.sh`を実行
